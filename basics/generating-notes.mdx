---
title: "Generating Notes"
description: "Generate Smart Fields from the editor, browser, and deck list."
---

Smart Notes can generate one note at a time or many notes in bulk.

## From the editor

Use the sparkle button in the Anki editor to generate Smart Fields for the note you are editing.

## From the browser

Use the Anki browser when you want to generate Smart Fields for selected notes.

1. Open **Browse**.
2. Search for the notes you want to update.
3. Select the notes.
4. Right-click and choose **Generate Smart Fields**.

## From the deck list

Use deck generation when you want to generate every matching note in a deck.

## Skipping existing values

Smart Notes is designed to avoid overwriting fields you already filled in unless you explicitly choose to regenerate them.
