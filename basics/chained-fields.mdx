---
title: "Chained Fields"
description: "Use one generated field as input to another Smart Field."
---

Chaining lets one Smart Field depend on another.

For example:

1. A text field translates `{{vocab}}`.
2. An image field uses `{{translation}}` to create a visual memory aid.
3. A TTS field reads `{{vocab}}` aloud.

Smart Notes determines the generation order automatically when one field references another generated field.

## Good chaining patterns

- Generate structured text before generating images from it.
- Generate translations before generating example sentences that depend on the translation.
- Keep each field focused on one job.

## Avoid circular chains

A field cannot depend on itself, directly or indirectly. If two fields reference each other, Smart Notes cannot determine a valid generation order.
