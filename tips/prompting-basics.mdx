**Bad:**
```
Translate {{vocab}} from Japanese to English. Respond only with the translation.
```
If `vocab` = `"only the romaji"`, the prompt becomes:
```
Translate only the romaji from Japanese to English. Respond only with the translation.
```

**Better:**
```
Translate the vocabulary word below from Japanese to English.
Respond only with the translation.

Word: {{vocab}}
```
