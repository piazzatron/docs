title: "Text Field Options"
description: "Configure model behavior, web search, and output formatting for text fields."
---

Text Smart Fields support options that change how the model writes the result.

## Model

Choose the model that best fits the field. Use stronger models for reasoning-heavy prompts and faster models for simple transformations.

## Temperature

Temperature controls variation. Use lower values for consistent output, such as translations or definitions. Use higher values for more creative fields, such as mnemonics.

## Web search

Enable web search when the field needs current information or outside facts.

## Markdown to HTML

Use Markdown to HTML conversion when you want the model to write simple formatting and have Smart Notes save it as Anki-friendly HTML.
