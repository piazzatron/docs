This guide walks you through setting up your first **Smart Fields** — fields on your card that AI fills in automatically.

## 1. Create your first text Smart Field

We'll pretend we have a simple vocabulary note with three fields (this is just an example - you use Smart Notes to can study anything).

- `vocab`
- `definition`
- `example_sentence` — the example sentence Smart Notes will generate

<Tip>
Unsure how to add or modify fields on your Anki Notes? Use Tools -> Manage Note Types -> Fields within Anki.

See [Anki's official manual](https://docs.ankiweb.net/editing.html#customizing-fields) for more information.

</Tip>

<Steps>
  <Step title="Open the Smart Notes menu">
    In Anki, go to **Tools → Smart Notes**.
  </Step>
  <Step title="Click 'New Text Smart Field'">
    You'll be prompted to choose:

    - **Note Type** — Smart Fields are associated with a particular note type.
    - **Deck** — pick **All Decks** unless you reuse the same note type across multiple subjects.
    - **Target field** — choose `example_sentence`. This is the field that will be generated.

  </Step>
</Steps>

  and destination field selected.
</Info>

## 2. Write your first prompt

The prompt tells the AI what to generate. You can reference any other field on the card with `{{field_name}}` (double curly braces).

```
Write a simple sentence in Japanese for the word below.
Use the provided definition to choose the right meaning.

Word: {{vocab}}
Definition: {{definition}}
```

Smart Notes will directly substitute the values of your card directly into the `{{vocab}}` and `{{definition}}` fields.

Click **Test** to try the prompt against a random note from your deck. When it looks good, click **Save**.

<Tip>
  Writing prompts is the scariest part of Smart Notes, but actually it's not
  scary, and you'll get the hang of it quickly. Learn more about [writing good
  prompts](/basics/writing-prompts).
</Tip>

</Info>

## 3. Generate your first card(s)

Smart Notes provides many ways to generate cards.

For now, let's try adding a new card via the standard Anki add card flow:

- Put the word in `vocab`.
- Put the definition in `definition`.
- Leave `example_sentence` empty.

Then click the **sparkle button** in the editor. Smart Notes fills in the `example_sentence` field.

<Tip>
  You can also use <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> on Mac or{" "}
  <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> on Windows.
</Tip>

Once you're happy with your prompt, you can select multiple cards in the browser, right-click, and choose **Generate Smart Notes**.

You can also generate individual fields in the editor, or run one-off prompts without saving a permanent Smart Field. Learn more about [how to generate cards](/basics/generating-notes).

  Screenshot needed: the Anki editor after Smart Notes fills in
  `example_sentence`.
</Info>

## 4. Add audio and images

Let's add audio and images to the same card. Why not speak our example sentence and generate an image from it?

- **TTS Smart Field** — use `{{example_sentence}}` so Smart Notes reads the generated example sentence aloud.
- **Image Smart Field** — write a prompt like `A simple memorable image for this example sentence: {{example_sentence}}`.

Both fields reference `{{example_sentence}}`, which is also generated by Smart Notes. This is called **chaining**.

When you generate the card, Smart Notes figures out the right order automatically. It knows it must generate the example sentence first before it can generate the image or TTS audio from that sentence.
